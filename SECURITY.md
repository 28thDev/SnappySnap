# Security reporting

Do not report credentials, private captures or exploitable vulnerabilities in a public issue.

Use [GitHub private vulnerability reporting](https://github.com/28thDev/SnappySnap/security/advisories/new), or open **Security → Advisories → Report a vulnerability** in this repository.

Include the affected version, impact, safe reproduction steps and any mitigations. Redact unrelated personal data. Do not attach a full application profile or signing material.

The supported version is the latest published 1.x release on Windows 11 x64. No response-time SLA is claimed.

The updater's catalog signature authenticates packages downloaded from GitHub Releases and cached locally; it is not an Authenticode certificate. Installer signing status must be stated accurately on each release. A compromised account that can replace its own installed application is outside that updater trust boundary.
