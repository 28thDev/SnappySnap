# SnappySnap 1.1.3 — release candidate

This installer is for owner testing before publication. It supersedes the 1.1.2 tester build and is not yet a stable GitHub release.

## Changes

- Take a series of screenshots while earlier editors stay open; each frame has its own saved original and editor session.
- Opacity values show rounded percentages, and Shelf commands have distinct icons.

- Fixed Print Screen appearing as an invalid default shortcut in Settings. Its display name now stays valid when captured, normalized and registered.
- The region selector highlights the visible window under the pointer. In Chrome, Edge and Firefox, hovering tabs proposes the whole browser, hovering the address toolbar proposes the toolbar and visible page without tabs, and hovering the page proposes only visible content. Click to accept, drag for a custom rectangle, or double-click during screenshot selection for the whole monitor.
- The address-and-page proposal begins at the detected top edge of the URL toolbar, including its controls when the boundary is reliable. If browser zones cannot be identified reliably, the selector offers the full window and says tabs will be included.
- Right-click cancels screenshot or video area selection. Print Screen captures the visible desktop across connected monitors, saves the screenshot to Shelf and opens the editor.
- Arrow, rectangle, line and freehand annotations start at 10 px and can reach 24 px. The old saved default of 5 px moves once to 10 px; other custom widths remain.
- Double-click or press Enter on a Shelf item to open SnappySnap's screenshot or video editor. The Open context action still opens the file in its Windows default app.

Screenshots with area selection remain frozen at hotkey time; video records a fixed rectangle.

## Testing status

Automated tests and off-screen WPF rendering passed. Physical selector, Print Screen delivery and browser checks in Chrome, Edge and Firefox are pending owner testing. Multi-monitor and mixed-DPI physical acceptance also remains open.

## Installation

`SnappySnap-Setup-1.1.3-x64.exe` targets Windows 11 x64. Exit SnappySnap from the tray before installing over an older version. Settings and captures are retained. The offline per-user installer includes .NET and the required Microsoft C++ runtime. The Setup executable has no Authenticode publisher signature, so Windows may show an unknown-publisher or reputation warning.
