# SnappySnap 1.0.0

SnappySnap is a Windows screenshot and recording utility. Captures stay local; no account, cloud uploads or telemetry are required.

## Included

- Frozen region screenshots with annotation, crop, clipboard copy and separate-copy saving.
- MP4/H.264 region recording, pause/resume, mouse-click indicators and system/microphone controls.
- Video trimming and middle-section removal, exporting to a new file.
- Capture history with thumbnails, multi-selection and drag-out.
- English, Russian, Simplified Chinese, Japanese and Spanish; System, Light and Dark appearance.
- Signed-catalog GitHub updates with explicit download and install actions.

## Install and update

Download **SnappySnap-Setup-1.0.0-x64.exe**. The source archives are for developers. Requires Windows 11 x64 build 22000 or newer. The offline per-user installer includes .NET and the required Microsoft C++ runtime; no administrator rights or prerequisite downloads are needed. Windows N requires the Windows Media Feature Pack for recording.

For manual installation over an existing version, finish recording/export, resolve editor changes and choose Exit from the tray first. Settings and captures are retained. Built-in updates use Settings → Updates → Download → Update and restart. Automatic checks can be disabled.

The installer is **not Authenticode-signed**. Windows may show an unknown-publisher/reputation warning. The signed update catalog authenticates the installer to SnappySnap and is separate from Windows publisher signing. `SHA256SUMS.txt` identifies the exact installer bytes.

## Requirements and limitations

- Windows 10 and ARM64 are not supported targets. Hardware encoding depends on the available device/driver; software fallback is supported.
- Uninstall retains captures and profile data. Deleting items in Shelf removes their media files.
