# SnappySnap 1.1.0 — release candidate

This installer is for owner testing before publication. It includes the complete set of changes since public 1.0.0 and is not yet published.

## Changes

- Fixed region capture failing when a proposed window extends outside the desktop. The highlight and captured output now use the visible intersection.
- The first screenshot opens the editor. While any screenshot editor remains open, including minimized, subsequent captures save directly to Shelf without opening additional editors. After all editors close, the next screenshot opens an editor again. A failed save opens an editor so the capture can be recovered.
- Open any number of screenshot editors manually from Shelf; each window keeps its own edits and save session. Concurrent saves remain tracked until all finish.
- Fixed opacity slider steps sticking and removed fractional tails from property labels.
- Print Screen captures the full virtual desktop; right-click cancels region selection. If Windows opens its own capture tool with Print Screen, SnappySnap reports the conflict in Hotkeys and Shelf and offers a different shortcut.
- Window and browser hover suggestions support full browser, address toolbar with page, and page content. Unrecognized browser layouts explicitly offer the full window with tabs.
- Arrow, rectangle, line and freehand widths default to 10 px and reach 24 px; custom preferences are preserved.
- Double-click, Enter or Edit in Shelf opens the built-in editor. Context actions have distinct icons. Open still uses the Windows default app.
- Fixed an H.264 recording failure when a selected browser or page region has odd pixel dimensions.
- Video history thumbnails now use decoded frames instead of Windows Shell previews. A recording that fails before creating media no longer claims a recoverable file.
- Recording start no longer puts a Windows notification over the selected capture area.

Region screenshots use the frame frozen at hotkey time. Video records a fixed rectangle. Saved captures remain individually editable through Shelf.

## Acceptance status

Automated geometry, state, persistence and editor tests and offscreen WPF scenarios passed. Physical hotkey delivery, the complete first/subsequent-editor interaction, browser boundaries, mixed-DPI displays and installation/upgrade remain pending owner acceptance.

## Installation

Current test build: **1.1.0-f**. Use `SnappySnap-Setup-1.1.0-f-x64.exe` on Windows 11 x64. Exit SnappySnap from its tray menu before installing. The offline per-user installer includes the required runtime; existing settings and captures are retained. The tester executable is not Authenticode-signed.

If an internal 1.1.1–1.1.5 build is installed, Setup refuses the downgrade. The transition through normal uninstall/reinstall with retained data still requires testing. Do not remove your captures or settings.

Test letters appear in Settings -> Updates and Setup. They do not change the numeric Windows version. The public installer will have no letter and requires a clean rebuild with TestBuildLabel empty.
