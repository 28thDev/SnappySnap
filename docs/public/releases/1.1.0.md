# SnappySnap 1.1.0 — historical tester notes

These notes describe the earlier internal build only. The intended public 1.1.0 must consolidate all accepted changes since public 1.0.0, including later internal tester fixes. Replace these historical notes during final release preparation; this file is not approval-ready public release text.

This installer is for owner testing before publication. It is not yet the stable GitHub release.

## Changes

- Arrows begin at 10 px and their thickness control reaches 24 px. Existing custom values remain; the former saved default of 5 px moves to 10 px once.
- After the screenshot or video hotkey, the selector highlights the visible window under the pointer. For Chrome, Edge and Firefox, tabs propose the whole browser, the address toolbar proposes the address bar and visible page without tabs, and the page proposes only its visible content.
- Click to accept the suggestion or drag to select any rectangle. Screenshot double-click still captures the full monitor. When the browser cannot provide trustworthy zone boundaries, the selector says that the proposed full-window capture includes tabs.

The screenshot remains frozen at hotkey time. Video records the chosen fixed rectangle and does not follow a moved window.

## Testing status

Automated tests and off-screen WPF rendering passed. Physical selector and recording checks in Chrome, Edge and Firefox are pending owner testing, including normal/maximized windows and bookmarks bars. Multi-monitor and mixed-DPI physical acceptance also remains open.

## Installation

`SnappySnap-Setup-1.1.0-x64.exe` targets Windows 11 x64. Exit SnappySnap from the tray before installing over an older version. Settings and captures are retained. The offline per-user installer includes .NET and the required Microsoft C++ runtime. The Setup executable has no Authenticode publisher signature, so Windows may show an unknown-publisher or reputation warning.
