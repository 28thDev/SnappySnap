# SnappySnap 1.1.0

SnappySnap captures and edits screenshots and MP4 recordings locally on Windows 11. This update improves region selection, screenshot editing and recording reliability.

## Changes since 1.0.0

- Window capture suggestions stay within the visible desktop, including when a window extends beyond its edge.
- Browser suggestions can distinguish the whole browser, its toolbar and page, or the page alone. When the page boundary cannot be identified reliably, the selector explicitly offers the whole browser with tabs.
- Print Screen captures the full desktop. If Windows intercepts that key, SnappySnap reports the conflict in Hotkeys and Shelf so you can choose another shortcut. Right-click cancels region selection.
- The first screenshot opens the editor. While an editor remains open, later captures save directly to Shelf. You can also open several saved screenshots in separate editors from Shelf.
- The editor's opacity slider, annotation widths, window sizing, and Shelf's Edit and Open actions have been refined. Saved screenshots remain individually editable.
- Regions with odd pixel dimensions can be recorded as H.264 video. Video thumbnails use decoded frames, and recording start does not place a Windows notification in the captured area.
- A failed recording start no longer claims that a recoverable file exists when no media was created.

Screenshot selection uses the frame frozen when the shortcut is pressed. Video continues to record a fixed rectangle after the source window moves.

## Install and update

Download **SnappySnap-Setup-1.1.0-x64.exe** from the release assets. The source-code archives are for developers. Setup is offline, installs for the current user, includes the required runtimes, and requires Windows 11 x64 build 22000 or newer. Windows 10 and ARM64 are not supported targets.

Before a manual update, finish recording or exporting, close editors, and exit SnappySnap through the tray menu. Installing over 1.0.0 retains captures, history, and preferences. If a preview build with a higher numeric version is installed, uninstall that build normally before installing 1.1.0; uninstall retains your captures and profile data. Back up important captures before changing installations.

The installer is **not Authenticode-signed**. Windows may show an unknown-publisher or reputation warning. SnappySnap's signed update catalog authenticates packages downloaded through the built-in updater; it does not give Setup a Windows publisher signature. `SHA256SUMS.txt` identifies the exact installer bytes. Updates are downloaded and installed only after you choose those actions in the app.

## Tested setup and limits

The release acceptance run covered Windows 11 x64 on one 1024×768 display at 100% scaling with working audio output. Multi-monitor and mixed-DPI layouts, Narrator, and live microphone sound were not independently validated for this build. Hardware encoding depends on the available device and driver; software fallback is supported. On Windows N, recording requires the Windows Media Feature Pack.

SnappySnap is MIT-licensed; bundled dependencies retain their own licenses. Microsoft Media Foundation supplies the recording and editing codecs; FFmpeg is not bundled.
