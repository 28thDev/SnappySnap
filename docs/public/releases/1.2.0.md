# SnappySnap 1.2.0 — DRAFT, not released

SnappySnap captures and edits screenshots and MP4 recordings locally on Windows 11. This update adds an optional editor step after a screenshot and refines the selector, recording controls and settings.

## Changes since 1.1.0

- **Open editor after capture** is a new option in Settings → Screenshots, on by default. When it is off, a screenshot is saved directly to Shelf and copied to the clipboard if automatic copy is enabled. Saved screenshots remain editable from Shelf. A failed save still opens the editor so the capture can be recovered.
- The browser suggestion for the address bar and page starts slightly above the toolbar, giving a clean top edge.
- The region selector's hint and outline stay readable in Light and Dark appearance.
- The recording pill shows a red indicator while recording and can be dragged to another position. It remains excluded from the recording.
- The screenshot editor places tools and actions on one row when the window is wide enough.
- Settings use consistent row spacing. A suggested alternative shortcut is shown next to the shortcut that has a conflict.
- The tray menu follows the selected appearance, Shelf cards show capture dimensions, and scroll bars are easier to see.
- An unexpected error is logged locally and reported in the notification area while SnappySnap keeps running.
- Recording no longer logs every mouse click. Only the ten most recent log files are kept.

## Install and update

Download **SnappySnap-Setup-1.2.0-x64.exe** from the release assets. The source-code archives are for developers. Setup is offline, installs for the current user, includes the required runtimes, and requires Windows 11 x64 build 22000 or newer.

Before a manual update, finish recording or exporting, close editors, and exit SnappySnap through the tray menu. Installing over 1.1.0 retains captures, history, and preferences.
