# SnappySnap 1.2.0 — release candidate

This installer is for owner testing before publication. It is not yet a stable GitHub release.

## Changes

- Right-click cancels screenshot or video area selection. Print Screen captures the visible desktop across connected monitors, saves the screenshot to Shelf and opens the editor.
- Rectangle, line and freehand annotations now start at 10 px and can reach 24 px. The old saved default of 5 px moves once to 10 px; custom widths remain.
- The address-bar-and-page browser suggestion begins at the detected top edge of the URL toolbar, including its controls when their boundary is available.
- Double-click or press Enter on a Shelf item to open SnappySnap's screenshot or video editor. The Open context action still opens the file in its Windows default app.

The selector still offers the whole browser when its address toolbar cannot be identified reliably. Screenshots with area selection remain frozen at hotkey time; video records a fixed rectangle.

## Testing status

Automated tests and off-screen WPF rendering passed. Physical selector, Print Screen registration and browser checks in Chrome, Edge and Firefox are pending owner testing. Multi-monitor and mixed-DPI physical acceptance also remains open.

## Installation

`SnappySnap-Setup-1.2.0-x64.exe` targets Windows 11 x64. Exit SnappySnap from the tray before installing over an older version. Settings and captures are retained. The offline per-user installer includes .NET and the required Microsoft C++ runtime. The Setup executable has no Authenticode publisher signature, so Windows may show an unknown-publisher or reputation warning.
